# alu-higher_level_programming

## Directory: javascript-warm_up

JavaScript warm-up scripts, run with Node.js. All scripts use `const`/`let` (no `var`) and follow the semistandard style.

| File | Description |
|------|-------------|
| 0-javascript_is_amazing.js | Prints "JavaScript is amazing" using a constant |
| 1-multi_languages.js | Prints 3 lines about C, Python and JavaScript |
| 2-arguments.js | Prints a message depending on the number of arguments |
| 3-value_argument.js | Prints the first argument |
| 4-concat.js | Prints two arguments as "a is b" |
| 5-to_integer.js | Prints the first argument as an integer |
| 6-multi_languages_loop.js | Prints 3 lines using an array and a loop |
| 7-multi_c.js | Prints "C is fun" x times |
| 8-square.js | Prints a square of X characters |
| 9-add.js | Prints the addition of 2 integers |
| 10-factorial.js | Computes a factorial recursively |
| 11-second_biggest.js | Finds the second biggest integer in the arguments |
| 12-object.js | Updates an object value from 12 to 89 |
| 13-add.js | Exports a function that adds 2 integers |

## Usage

    chmod +x *.js
    ./0-javascript_is_amazing.js
