# python-input_output

This directory contains Python exercises on file input/output and JSON
serialization, covering reading and writing text files, converting Python
objects to and from JSON, and building simple serialization/deserialization
mechanisms with a Student class.

## Tasks

- **0-read_file. reads a UTF8 text file and prints it to stdoutpy** 
- **1-write_file. writes a string to a UTF8 text file, returns chars writtenpy** 
- **2-append_write. appends a string to a UTF8 text file, returns chars addedpy** 
- **3-to_json_string. returns the JSON representation of an objectpy** 
- **4-from_json_string. returns an object from a JSON stringpy** 
- **5-save_to_json_file. writes an object to a file as JSONpy** 
- **6-load_from_json_file. creates an object from a JSON filepy** 
- **7-add_item. script that adds CLI arguments to a list saved as JSONpy** 
- **8-class_to_json. returns a dictionary description of an object for JSONpy** 
- **9-student. a `Student` class with a `to_json` methodpy** 
- **10-student. `Student` with a filterable `to_json` methodpy** 
- **11-student. `Student` with `to_json` and `reload_from_json`py** 
- **12-pascal_triangle. builds Pascal's triangle as a list of listspy**
