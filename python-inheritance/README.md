# python-inheritance

This directory contains Python exercises on class inheritance, covering
object introspection, class hierarchies, and building a small geometry
class system using inheritance and validation.

## Tasks

- **0-lookup. returns the list of available attributes and methods of an objectpy** 
- **1-my_list. a `MyList` class that inherits from `list`, with a `print_sorted` methodpy** 
- **2-is_same_class. checks if an object is exactly an instance of a given classpy** 
- **3-is_kind_of_class. checks if an object is an instance of, or inherits from, a given classpy** 
- **4-inherits_from. checks if an object's class inherits from another classpy** 
- **5-base_geometry. an empty `BaseGeometry` classpy** 
- **6-base_geometry. `BaseGeometry` with an `area()` method that raises an exceptionpy** 
- **7-base_geometry. `BaseGeometry` with an `integer_validator` methodpy** 
- **8-rectangle. a `Rectangle` class with private, validated `width` and `height`py** 
- **9-rectangle. `Rectangle` with an `area()` method and a string representationpy** 
- **10-square. a `Square` class that inherits from `Rectangle`py** 
- **11-square. `Square` with its own string representationpy**
